Words in English have favourite partners. We say **make a decision**, not "do a decision". We say **do research**, not "make research". These word partners are called **collocations**. There is no logical rule. The only way is to learn them in pairs. The good news: a small number of verbs (make, do, take, give, have, get) cover a large share of everyday collocations, and learning them removes many of the mistakes that make English sound "translated".

> **Hinglish mein:** Hindi mein hum sab ke liye "karna" use karte hain (decision karna, research karna, meeting karna). English mein alag verbs hote hain: make a decision, do research, have a meeting. Inhe pairs mein yaad karo.

## Make, do, take, give, have, get

| Verb | Common partners |
| --- | --- |
| **make** | a decision, a mistake, progress, a plan, a suggestion, an effort, a change, a call, sense, a point |
| **do** | the work, research, a favour, your best, business, damage, an exercise, the dishes |
| **take** | a break, notes, a look, responsibility, a photo, time, a decision (British), place, care, an exam |
| **give** | feedback, an example, a presentation, a hand (help), a reason, permission, advice |
| **have** | a meeting, a look, a problem, a chat, an idea, a question, a conversation, lunch |
| **get** | approval, feedback, access, started, stuck, better, a reply, permission |

## Tech and workplace collocations

| Collocation | Example |
| --- | --- |
| fix a bug | I fixed the bug yesterday. |
| raise an issue | I raised an issue on GitHub. |
| open / close a ticket | Please close the ticket when it is done. |
| push changes | I pushed my changes to the branch. |
| merge a branch | We merged the branch after the review. |
| handle an error | The code handles the error correctly. |
| meet / miss a deadline | We met the deadline. We missed the deadline. |
| reach a decision | The team reached a decision quickly. |
| run a test | Run the tests before the release. |
| ship a feature | We shipped the feature last week. |
| write / review code | She reviews my code every day. |
| hold a meeting | We hold the stand-up at 10 am. |

## Common mistakes

| Wrong | Correct |
| --- | --- |
| do a mistake | make a mistake |
| make a research | do research |
| take a feedback | get / receive feedback |
| do a meeting | have a meeting |
| give an exam | take an exam |
| make a photo | take a photo |
| do a plan | make a plan |
| keep a meeting | hold / have a meeting |
| make the work | do the work |

## Make a decision or take a decision?

Both are used. **Make a decision** is common in American English and is safe everywhere. **Take a decision** is common in British and Indian English. If you work with an international team, prefer **make a decision**.

## Say them aloud

```phrases
We need to make a decision by Friday.
I did some research on caching options.
Could you give me some feedback on my code?
Let's take a short break and have a quick chat.
We met the deadline and shipped the feature.
I got approval from my manager to start the migration.
```

## How to learn collocations

1. When you learn a new noun, **always learn its verb partner**: not "decision", but "make a decision".
2. Keep a notebook page with six columns: make, do, take, give, have, get.
3. When you read an email or a document, underline the verb and noun pairs.
4. Write five sentences each day with a new pair, and say them aloud.

## Practice

Fill in make, do, take, give, have or get.

1. Could you ___ me some feedback? Answer: give
2. I need to ___ a decision. Answer: make
3. Let's ___ a break. Answer: take
4. We ___ a meeting every Monday. Answer: have
5. I ___ some research last night. Answer: did

## Recap

- Learn verb and noun pairs, not single words.
- Make a decision, do research, take a break, give feedback, have a meeting, get approval.
- Prefer "make a decision" in international teams.
- Underline pairs in what you read and use them in your own sentences.
