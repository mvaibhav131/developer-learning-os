Work depends on asking other people for things: a review, a file, an answer, a decision. In many Indian workplaces direct requests ("Send it today") are normal. In international teams, they can sound demanding. The good news: polite requests are made from a small set of patterns that you can learn in one lesson.

> **Hinglish mein:** Request mein teen cheezein hoti hain: naram shuruaat ("Could you..."), kya chahiye, aur kab tak aur kyun. Reminder bhejte waqt gussa nahi, seedhi aur dostana baat likho.

## Polite request patterns

| Pattern | Example |
| --- | --- |
| Could you...? | Could you send me the report by Friday? |
| Would you mind + -ing? | Would you mind reviewing my pull request? |
| I was wondering if you could... | I was wondering if you could share the API documentation. |
| Would it be possible to...? | Would it be possible to move the meeting to Thursday? |
| It would be great if... | It would be great if you could review it today. |

A good request has **what**, **by when** and **why**: "Could you review my pull request by Thursday? We plan to release on Friday."

## Direct and polite

| Too direct | Polite |
| --- | --- |
| Send me the file. | Could you send me the file, please? |
| Reply today. | Could you reply by the end of today? I need it for the demo. |
| Review my code. | Would you mind taking a look at my code when you have time? |
| Why no reply? | Just checking whether you had a chance to look at my message. |

## Reminders and follow-ups

Do not wait too long, and do not send reminders too often. A common rule: the first reminder after **two working days**, the second after **another two or three days**. Then try a call or talk to a manager.

| Step | Example |
| --- | --- |
| First reminder | Just a quick reminder about the API key. Could you send it when you have a moment? |
| Second reminder | Following up on my earlier message. I need the key by tomorrow to finish testing. |
| Last step | Could we have a five-minute call to solve this? |

Avoid: "As I told you earlier", "Why have you not replied?", "Reminder 3".

## Saying no or later politely

You can say no without being rude. Give a short reason and offer another time.

| Situation | Say |
| --- | --- |
| You cannot do it now | I'm afraid I can't do it today. I can finish it by Wednesday. |
| You are busy | I'm in the middle of a release. Could we talk tomorrow? |
| You do not agree to the deadline | Friday might be difficult because of the testing. Would Monday work? |
| You need more information | Could you tell me more about what you need? |

## Thanking

```phrases
Thanks for your quick help.
I really appreciate it.
Thank you for letting me know.
Thanks for taking the time to review this.
I'm afraid I can't do it today. I can finish it by Wednesday.
Just a quick reminder about the API key. Could you send it when you have a moment?
```

## Template: a polite reminder

```text
Subject: Reminder: staging API key

Hi Anil,

Just a quick reminder about the staging API key. I need it to finish
the integration tests, and the demo is on Friday.

Could you send it by tomorrow if possible?

Thanks for your help,
Rahul
```

## Practice

1. Rewrite "Send me the file today" in three polite ways.
2. Write a first reminder and a second reminder for something you are waiting for.
3. Write a polite message that says "I can't do it today, but I can finish it tomorrow".

## Recap

- Use polite patterns: could you, would you mind, would it be possible.
- Give what, by when and why.
- First reminder after two working days. Keep the tone friendly.
- Say no or later with a reason and an alternative.
