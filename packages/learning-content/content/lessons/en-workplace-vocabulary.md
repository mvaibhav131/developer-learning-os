A big vocabulary is not the goal. A **useful** vocabulary is. About 100 words appear again and again in meetings, tickets, chat and code reviews. If you know these well, you will understand much more and speak faster. This lesson groups the words by situation. Every table has a **Download table as CSV** button, so you can open the list in a spreadsheet or import it into a flashcard app.

> **Hinglish mein:** Har word ko ek sentence ke saath yaad karo, sirf meaning se nahi. Neeche ki tables ka CSV download karke Excel ya flashcard app mein daal lo, aur roz 5 words revise karo.

## Meetings and planning

| Word | Meaning | Example |
| --- | --- | --- |
| agenda | list of topics for a meeting | The agenda has three items. |
| minutes | written notes of a meeting | I'll send the minutes after the call. |
| action item | a task that someone must do after a meeting | The action item is to update the API docs. |
| deadline | the last date to finish something | The deadline is Friday. |
| postpone | move to a later time | We postponed the demo to Monday. |
| reschedule | change the time of a meeting | Could we reschedule to 4 pm? |
| attend | be present at a meeting | Please attend the review on Tuesday. |
| follow up | check or continue after a first contact | I'll follow up with the client tomorrow. |

## Projects and process

| Word | Meaning | Example |
| --- | --- | --- |
| requirement | something the product must do | The main requirement is two-factor login. |
| scope | everything included in a project | Reports are out of scope for this release. |
| milestone | an important step in a project | The first milestone is the prototype. |
| deliverable | something you must hand over | The deliverable is a working API. |
| backlog | the list of tasks not yet done | We added the idea to the backlog. |
| sprint | a short work period, often two weeks | We finish this feature in the next sprint. |
| estimate | a guess of time or effort | My estimate is three days. |
| priority | how important something is | This bug is high priority. |

## Code and technology

| Word | Meaning | Example |
| --- | --- | --- |
| bug | a mistake in the code | I found a bug in the search page. |
| patch | a small fix | We released a patch for the login error. |
| deploy | release code to a server | We deploy every Friday. |
| roll back | return to the previous version | We rolled back the release after the crash. |
| refactor | improve code without changing what it does | I'll refactor the payment service. |
| dependency | a library or service your code needs | We updated an old dependency. |
| outage | a time when the service is down | The outage lasted twenty minutes. |
| environment | a place where the software runs | The bug only happens in the staging environment. |

## Communication

| Word | Meaning | Example |
| --- | --- | --- |
| clarify | make something clear | Could you clarify the requirement? |
| confirm | check or agree that something is true | Please confirm the date. |
| escalate | tell a more senior person about a problem | I escalated the issue to my manager. |
| summarise | give the main points | Let me summarise the discussion. |
| approve | officially agree | The manager approved the change. |
| raise | bring up an issue | I'd like to raise a concern. |

## Example sentences to say aloud

```phrases
The deadline is Friday, so we need to confirm the scope today.
I'll send the minutes and the action items after the meeting.
We rolled back the release because of an outage in production.
Could you clarify the requirement for the login page?
I escalated the issue to my manager.
This task is high priority, and my estimate is two days.
```

## How to learn the words

1. Choose **five words** per day. Not more.
2. Write each one in a **new sentence about your own work**.
3. Say the sentence aloud, and use one word in a real conversation or message.
4. Use the CSV download to import the table into a flashcard app, and review the cards for five minutes daily.
5. After a week, check which words you still forget, and keep only those on your list.

## Recap

- Learn words in sentences and in groups.
- Five words a day, used the same day, are better than fifty words you only read.
- Download the tables as CSV for flashcards.
- Use new words in your stand-up and in your messages this week.
