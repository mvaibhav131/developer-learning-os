When you talk about the past, English gives you two main choices. The **past simple** is for a finished action at a finished time. The **present perfect** connects the past with now. This choice is where many Hindi speakers make mistakes, because Hindi has one "tha / chuka hai" pattern for both.

> **Hinglish mein:** "Maine kal bug fix kiya" = past simple (kal = finished time). "Maine bug fix kar diya hai" = present perfect (abhi uska result hai). Agar time clearly past mein hai (yesterday, last week, in 2023), past simple use karo.

## Past simple

Use it for actions that are finished and for a clear time in the past.

- I **fixed** the bug yesterday.
- We **released** version 2 last week.
- She **joined** the company in 2023.

Form: regular verbs add **-ed** (fix -> fixed, deploy -> deployed). Irregular verbs change (write -> wrote). Negative: **did not (didn't) + base verb**. Question: **Did + subject + base verb**.

## Present perfect

Form: **have / has + past participle**. Use it when the time is not important or not finished.

| Use | Example |
| --- | --- |
| A result that matters now | I **have fixed** the bug. It works now. |
| Life experience (ever, never) | **Have you ever used** Docker? / I **have never worked** with Rust. |
| Just, already, yet | The build **has just finished**. I **have already sent** the report. They **haven't replied yet**. |
| A period that started in the past and continues | I **have worked** here **for** three years. |

## Past simple or present perfect?

| If you say... | Use | Example |
| --- | --- | --- |
| A finished time (yesterday, last week, in 2023, two days ago) | Past simple | I **fixed** it **yesterday**. |
| No time, or time up to now (ever, never, just, already, yet, so far, today) | Present perfect | I **have fixed** it. |
| For or since, and it still continues | Present perfect | I **have worked** here **since** 2022. |

Never mix the present perfect with a finished time: **I have seen him yesterday** is wrong. Say **I saw him yesterday.**

## For and since

- **for** + length of time: for three years, for two hours, for a long time
- **since** + starting point: since 2022, since Monday, since I joined

I have been learning English **for** six months. I have been learning English **since** January.

## Useful irregular verbs

| Base | Past simple | Past participle |
| --- | --- | --- |
| go | went | gone |
| do | did | done |
| write | wrote | written |
| break | broke | broken |
| run | ran | run |
| build | built | built |
| send | sent | sent |
| begin | began | begun |
| choose | chose | chosen |
| find | found | found |
| know | knew | known |
| see | saw | seen |
| take | took | taken |
| give | gave | given |

Push, fix, deploy, merge and test are regular: pushed, fixed, deployed, merged, tested.

## Sentences for stand-ups and updates

```phrases
I fixed the login bug yesterday.
I have finished the API changes.
We have not heard back from the client yet.
She has worked on this service for two years.
Did you push your changes this morning?
I have already updated the documentation.
```

## Practice

Choose past simple or present perfect.

1. We (release) the new version last Friday.
2. I (already / write) the tests.
3. (you / ever / use) Kubernetes?
4. She (work) here since 2021.

Answers: 1. released. 2. have already written. 3. Have you ever used. 4. has worked.

Now write two sentences about something you did yesterday and two about something you have done this week. Say them aloud.

## Recap

- Past simple: finished action, finished time. Did + base verb for questions and negatives.
- Present perfect: have or has + past participle. For results, experience and unfinished periods.
- Never use yesterday, last week or ago with the present perfect.
- Use for with a length of time and since with a start point.
- Learn irregular verbs in small groups, and say them aloud.
