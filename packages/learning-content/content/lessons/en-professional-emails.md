A good work email is short, clear and easy to act on. The reader should know within five seconds what you want and by when. Many emails fail not because of grammar but because the purpose is hidden, the tone is too formal or too direct, or the writer uses phrases that sound strange to people outside India. This lesson gives you a structure and templates that you can copy.

> **Hinglish mein:** Email ka formula: clear subject, ek line mein purpose, chhote paragraphs, aur end mein saaf action ("Please send me X by Friday"). "Kindly do the needful" jaise phrases ki jagah seedhi baat likho.

## The structure of a good email

| Part | What to write | Example |
| --- | --- | --- |
| Subject | Specific: topic + action | Action needed: review pull request 482 by Thursday |
| Greeting | Match the person | Hi Priya, / Hello team, / Dear Mr. Sharma, |
| Purpose | One sentence | I'm writing to ask for a review of the login changes. |
| Details | Short paragraphs or bullets | The change affects two files. I've added tests. |
| Action | What, who and when | Could you review it by Thursday? |
| Closing | Polite and short | Thanks, / Best regards, / Kind regards, |
| Signature | Name, role | Rahul Verma, Backend Developer |

## Subject lines

| Weak | Strong |
| --- | --- |
| Hi | Question about the login API response format |
| Urgent!!! | Production issue: payment page is slow (needs review today) |
| Leave | Leave request: 12 to 14 November |
| Doubt | Question about the deployment steps |

## Tone

- Be polite and direct. "Could you please send me the report by Friday?" is better than "Kindly do the needful."
- Use **please** and **thank you**, but do not repeat them in every sentence.
- Avoid long sentences. Fifteen to twenty words is a good limit.
- Avoid "As per my last email". It can sound angry. Say "As I mentioned earlier" or just repeat the information.

## Phrases to replace

| Instead of | Write |
| --- | --- |
| Please find attached herewith the document. | I've attached the document. |
| Kindly revert back at the earliest. | Please let me know by Friday. |
| Dear Sir/Madam | Hello, (or use the name) |
| Do the needful. | Please update the ticket by Monday. |
| I am writing this mail to inform you that | (Start with the point.) |

## Template 1: a request

```text
Subject: Request: review of login API changes by Thursday

Hi Priya,

I've opened a pull request for the login API changes: <link>.
It changes two files and adds tests for special characters.

Could you review it by Thursday? We plan to release on Friday.

Thanks,
Rahul
```

## Template 2: a status update or delay

```text
Subject: Update: payment tests will be ready on Monday

Hi team,

The payment tests are 80% done. I found a problem with the test data,
so I need one more day. I expect to finish on Monday.

Please let me know if this is a problem for the release.

Best regards,
Rahul
```

## Template 3: a polite follow-up

```text
Subject: Follow-up: API key for the staging server

Hi Anil,

I'm following up on my message from Tuesday about the staging API key.
I need it to continue the integration tests.

Could you send it by tomorrow, if possible?

Thanks,
Rahul
```

## Check before you press send

1. Is the **subject** specific?
2. Is the **action** clear: what, who and by when?
3. Is there **one topic** in this email?
4. Are the **To and Cc** people correct?
5. Did you attach the file?
6. Did you read it once, aloud or silently?

## Practice

1. Write a request email to a colleague for a code review. Use Template 1.
2. Write a short delay update to your manager. Use Template 2.
3. Read both aloud. Replace every long sentence with two short ones.
4. Save your best email as your own template.

## Recap

- Specific subject, one-line purpose, short details, a clear action.
- Be polite and direct. Avoid "kindly revert", "do the needful" and "as per my last email".
- Use templates, and check To, Cc and attachments before sending.
