Every English word with two or more syllables has **one strongest syllable**. That syllable is longer, louder and a little higher. If you stress the wrong syllable, people may not recognise the word, even when every sound is correct. This is especially important for tech words, because many of them are long.

> **Hinglish mein:** Hindi mein har syllable lagbhag barabar zor se bolte hain. English mein ek syllable par zor dete hain aur baaki ko halka aur chhota bolte hain. "dee-PLOY-ment" bolo, "de-ploy-MENT" nahi.

## How stress sounds

The stressed syllable is **longer, louder and higher**. The other syllables become short and weak. In the table the stressed syllable is in capital letters.

| Word | Stress |
| --- | --- |
| table | TA-ble |
| computer | com-PU-ter |
| information | in-for-MA-tion |

## Tech words to learn

| Word | Say it like this |
| --- | --- |
| algorithm | AL-go-ri-thm |
| architecture | AR-ki-tec-ture |
| authentication | au-then-ti-CA-tion |
| asynchronous | a-SYN-chro-nous |
| boolean | BOO-le-an |
| configuration | con-fig-u-RA-tion |
| database | DA-ta-base |
| deployment | de-PLOY-ment |
| environment | en-VI-ron-ment |
| function | FUNC-tion |
| integer | IN-te-ger |
| parameter | pa-RA-me-ter |
| recursion | re-CUR-sion |
| repository | re-PO-si-to-ry |
| security | se-CU-ri-ty |
| variable | VAR-i-a-ble |

The letters in an abbreviation are stressed on the last letter: **A-P-I**, **U-R-L**. Python is PY-thon and Java is JA-va.

## Rules of thumb

- Two-syllable **nouns and adjectives** are usually stressed on the first syllable: TA-ble, CLEAN-er, SER-ver.
- Two-syllable **verbs** are usually stressed on the second syllable: de-PLOY, re-TURN, com-PILE.
- Words ending in **-tion, -sion, -ic, -ical, -ity, -graphy**: stress the syllable just before the ending. (au-then-ti-CA-tion, al-go-RITH-mic, se-CU-ri-ty)
- Words with **-ment, -ness, -ful, -less, -ing** do not change the stress of the root word: DE-ploy -> de-PLOY-ment.

## Noun or verb? Stress changes the meaning

Some words are both noun and verb. The first syllable is stressed for the noun, the second for the verb.

| Word | Noun | Verb |
| --- | --- | --- |
| record | REC-ord | re-CORD |
| project | PRO-ject | pro-JECT |
| object | OB-ject | ob-JECT |
| increase | IN-crease | in-CREASE |
| permit | PER-mit | per-MIT |

## Weak syllables

Unstressed syllables are often reduced to a short "uh" sound. In "data" and "problem", the last syllable is weak. Do not say every vowel clearly, or the word will sound flat and hard to follow.

## Say them aloud

```phrases
The deployment pipeline checks the configuration automatically.
Authentication happens before the database connection.
The algorithm returns an integer.
Please record the environment variables in the repository.
The asynchronous function takes one parameter.
We need better security for this architecture.
```

## Practice

1. Choose ten words you use every day at work.
2. Look each word up in an online dictionary that has audio. Listen to it three times.
3. Write the word with the stressed syllable in capital letters.
4. Say it five times, exaggerating the stress.
5. Use it in one sentence in your next stand-up.

## Recap

- Each word has one strongest syllable: longer, louder, higher.
- Verbs with two syllables are usually stressed on the second syllable. Nouns on the first.
- Words ending in -tion, -ic and -ity are stressed before the ending.
- Weak syllables are short. Keep the strong one clear.
