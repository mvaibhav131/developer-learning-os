Hindi does not have articles, so **a, an and the** are hard for Hindi speakers. Do not worry about being perfect. Native speakers understand you without them. But a few simple rules will remove most of your mistakes, and they will make your writing in emails and pull requests look professional.

> **Hinglish mein:** "A / an" ka matlab "koi ek" (pehli baar, kisi bhi ek cheez ke liye). "The" ka matlab "woh wali cheez jo hum dono jaante hain". Kuch cheezon ke saath koi article nahi lagta (jaise languages, plurals in general).

## A and an: one of many

Use **a** or **an** with a singular, countable noun when you mention it for the first time, or when it can be any one of many.

- I found **a** bug in the login code.
- She is **an** engineer.
- We need **a** new server.

Choose **a** or **an** by the **sound**, not the spelling.

| Use | Sound | Examples |
| --- | --- | --- |
| an | starts with a vowel sound | an API, an error, an HTTP request, an hour, an MVP |
| a | starts with a consonant sound | a user, a URL, a unique ID, a one-time password |

## The: the specific one

Use **the** when both you and the listener know which one you mean.

- **The** server is down. (the one we both use)
- Open **the** terminal and run **the** tests.
- I found a bug. **The** bug is in the login code. (second mention)
- It is **the** fastest option. (superlatives and first, last, only)
- **The** internet is slow today. (only one in the world)

## No article

Use no article in these common cases.

| Case | Example |
| --- | --- |
| Plural nouns in general | Developers write tests. Bugs are expensive. |
| Uncountable nouns in general | Information is power. Software needs maintenance. |
| Languages, subjects, tools as a name | I use Python and Docker. I study English. |
| Names of people and most places | Rahul works in Pune. |
| Branch names and file names | Push to main. Open README.md. |
| Work, home, school with "go / at" | I go to work. He is at home. |

## Decision guide

1. Is the noun plural or uncountable and you mean it in general? **No article.**
2. Do you and the listener both know exactly which one? **the.**
3. Is it one of many, or the first time you mention it? **a / an.**

## Developer examples

```phrases
I found a bug in the login module.
Please open a pull request for the fix.
The API returns an error when the token is missing.
We use Python and Docker in this project.
Can you update the README before the release?
She is an experienced backend engineer.
```

## Common mistakes

| Wrong | Correct |
| --- | --- |
| I have laptop. | I have a laptop. |
| She is engineer. | She is an engineer. |
| I use the Python. | I use Python. |
| The Java and JavaScript are different. | Java and JavaScript are different. |
| I go to the work by bus. | I go to work by bus. |
| Please send me a feedback. | Please send me some feedback. |

## Practice

Fill in a, an, the or nothing.

1. I need ___ new laptop. Answer: a
2. ___ tests are failing again. Answer: The (specific tests) 
3. She works as ___ data engineer. Answer: a
4. He is ___ honest developer. Answer: an
5. I like ___ Python. Answer: nothing
6. Please check ___ logs. Answer: the

Read an error message aloud and say whether it uses a, an, the or nothing. Write five sentences about your project using a, an and the correctly.

## Recap

- a / an: one of many, first mention. an before vowel sounds.
- the: specific and known, second mention, superlatives, unique things.
- No article: plurals and uncountables in general, languages, tools, names.
- Do not stop speaking because of articles. Improve them slowly through reading and shadowing.
