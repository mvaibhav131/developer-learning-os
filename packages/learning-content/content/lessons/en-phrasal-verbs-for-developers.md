A phrasal verb is a verb with a small word (a particle) such as **up, out, on, off, in or back**. The meaning is often different from the single words. "Set up" is not "put up". Native speakers use phrasal verbs all the time in meetings and chats, and many are more natural than a formal verb: "figure out" is more common than "determine". When you know about thirty of them, English at work becomes much easier to understand.

> **Hinglish mein:** Phrasal verb = verb + chhota word (up, out, off...) jiska matlab alag ho jaata hai. "Look up" = shabd dhoondhna, "look into" = jaanch karna. Inhe pairs mein yaad karo, alag-alag nahi.

## Phrasal verbs for developers

| Phrasal verb | Meaning | Example |
| --- | --- | --- |
| set up | install or prepare | I'm setting up the project on my laptop. |
| log in / log out | enter or leave an account | Please log in with your work email. |
| sign up | create an account | I signed up for the trial. |
| look into | investigate | I'll look into the error today. |
| look up | search for information | Look up the word in a dictionary. |
| figure out | find the answer | I couldn't figure out why the test failed. |
| find out | discover | Let me find out who owns this service. |
| run into | meet a problem by chance | I ran into an error during the build. |
| break down | divide into smaller parts / stop working | Let's break down the task. The server broke down. |
| back up | make a copy | Back up the database before the update. |
| roll back | return to an older version | We rolled back the release. |
| roll out | release step by step | We'll roll out the feature to 10 percent of users. |
| hand over | give responsibility to someone | I'll hand over my tasks before I go on leave. |
| carry out | do or perform | We carried out a load test. |
| point out | draw attention to | Thanks for pointing out the mistake. |
| bring up | mention a topic | Could you bring up the issue in the meeting? |
| come up with | think of | We came up with a faster solution. |
| follow up | continue after the first contact | I'll follow up with the client tomorrow. |
| check in | contact to see progress | I'll check in with the team at noon. |
| clean up | make something tidy | Let's clean up the old branches. |
| fill in | add information | Please fill in the form. |
| turn down | refuse | He turned down the offer. |
| call off | cancel | They called off the meeting. |
| put off | delay | Don't put off writing the tests. |
| wrap up | finish | Let's wrap up the meeting. |
| step in | join to help | My manager stepped in to solve the conflict. |

## Word order

Some phrasal verbs can be **separated** by an object, and some cannot.

| Type | Example | Rule |
| --- | --- | --- |
| Separable | turn **off** the server / turn the server **off** | With a pronoun, the pronoun goes **in the middle**: turn **it** off. (not "turn off it") |
| Inseparable | look **into** the error | The object always comes after: look into **it**. |

Examples: Back **it** up. Set **them** up. Figure **it** out. But: look into **it**, run into **a problem**.

## Say them aloud

```phrases
I'll look into the error and get back to you.
We couldn't figure out why the build failed.
Please back up the database before the update.
We rolled back the release after the crash.
I'll follow up with the client tomorrow.
Let's wrap up the meeting and set up the next one.
```

## Common mistakes

| Wrong | Correct |
| --- | --- |
| I will check in the issue. | I will look into the issue. |
| Please turn off it. | Please turn it off. |
| We came up the idea. | We came up with the idea. |
| I ran into with a problem. | I ran into a problem. |

## Practice

Complete with a phrasal verb from the list: set up, figure out, roll back, follow up, wrap up.

1. I can't ___ why the API returns null. Answer: figure out
2. We had to ___ the release. Answer: roll back
3. I'll ___ with the client by email. Answer: follow up
4. It takes ten minutes to ___ the project. Answer: set up
5. Let's ___ the meeting. Answer: wrap up

## Recap

- Phrasal verbs are normal in work English.
- Learn them in sentences, with the full phrase.
- Pronouns go in the middle of separable phrasal verbs.
- Use five new ones this week in your stand-up or in chat.
